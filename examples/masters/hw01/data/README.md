# WAGE1 数据来源

本目录 WAGE1.DTA 是课程文件 `作业/Data/WAGE1.DTA` 的逐字节副本，方便同学下载样本后直接运行。文件内容未修改。

公开来源与变量定义：[Wooldridge 数据说明](https://justinmshea.github.io/wooldridge/reference/wage1.html)。该说明记载数据来自 1976 年美国 Current Population Survey。

原文件包含 526 条观察及 24 个变量。本样本选用 wage、educ、exper、female 四个变量；exper 是潜在工作经验。
