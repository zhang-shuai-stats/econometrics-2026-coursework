# 参考样本数据

本目录 `HTV.DTA` 为课程文件 `作业/Data/HTV.DTA` 的逐字节副本，内容未修改。课件例 9 给出工资模型但未指定数据文件，本样本选用 HTV 中对应的四个变量演示 FWL 定理。

原文件包含 1,230 条观察和 23 个变量；代码只使用 wage、educ、exper、abil。变量含义以数据标签为依据，abil 是未标准化的能力测量指标。
