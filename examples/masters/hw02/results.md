# 工资参考样本的运行结果

本页整理自随附 [main.do](main.do) 的实际运行日志；[完整回归结果见这里](results/run.log)。

## 样本

使用 `data/HTV.DTA`，仅保留 `wage`、`educ`、`exper`、`abil` 四个变量。删除任意一个所用变量缺失的观察；筛选前 1,230 条，删除 0 条，筛选后 1,230 条。直接回归、第一步辅助回归和第二步回归都使用这 1,230 条观察。

## 系数比较

| 方法 | 对应系数 | 估计值 |
|---|---|---:|
| 直接回归：`wage` 对 `educ exper abil` | `educ` | 1.701564411 |
| 两步法：先将 `educ` 对 `exper abil` 回归取残差，再将 `wage` 对残差回归 | `educ_resid` | 1.701564411 |
| 直接回归减两步法 | 使用未四舍五入的系数计算 | 约 $1.332\times10^{-15}$ |

两种方法得到的教育系数在数值精度内相等。第一步的 `educ_resid` 是教育年限中无法被工作经验、能力测量指标和截距线性解释的部分；用这部分教育变动与工资进行回归，得到的斜率与直接回归中控制上述变量后的教育系数相同。这就是本例展示的 FWL 系数关系。

两步法第二步的标准误、截距和 R 平方一般与直接回归不同，本次无需将整张回归表逐项匹配。这个系数关系是 OLS 的代数性质，不能据此认定教育对工资的因果效应已经被识别。
