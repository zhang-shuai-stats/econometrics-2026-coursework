# 研究设计参考样本

## 研究题目

**增值税留抵退税政策是否促进企业创新？------基于政策冲击的因果识别**

------------------------------------------------------------------------

## 1. 因果图（DAG）

``` text
          企业规模
             ↓
行业特征 → 留抵退税政策 → 企业研发投入
             ↓              ↑
          现金流改善 ────────┘

          宏观经济冲击 → 企业研发投入
```

核心机制：

留抵退税政策\
→ 缓解企业现金流约束\
→ 增加研发投入。

------------------------------------------------------------------------

## 2. 估计对象、处理、结果和样本

### 估计对象

政策实施后，获得留抵退税企业相对于未获得企业的平均研发投入变化（ATT）。

### 处理变量

企业是否受到留抵退税政策影响：

\[ Treatment_i `\times `{=tex}Post_t \]

其中：

-   Treatment=1：符合政策条件企业；
-   Post=1：政策实施以后。

### 结果变量

企业创新：

-   研发投入占营业收入比例；
-   发明专利申请数量。

### 样本

2018---2024年A股制造业上市公司面板数据。

------------------------------------------------------------------------

## 3. 识别论证

本文利用留抵退税政策作为外生政策冲击，采用双重差分模型识别政策对企业创新的影响。核心识别假设是：如果没有留抵退税政策，不同处理组企业和对照组企业的创新趋势应保持平行。

政策实施前，通过事件研究法检验处理组和对照组是否存在显著差异趋势。如果政策前不存在显著的提前反应，则支持平行趋势假设。

此外，模型控制企业固定效应、年份固定效应以及行业×年份固定效应，以控制企业不随时间变化的特征以及行业层面的共同冲击。

由于留抵退税政策主要针对符合条件企业，并非随机实施，因此本文进一步利用企业规模、行业特征等变量进行匹配或加权，提高处理组和对照组的可比性。

如果政策显著提高企业研发投入，并且结果在不同模型设定、样本选择和替代指标下保持稳定，则可以认为留抵退税政策促进企业创新的因果效应具有较强可信度。

------------------------------------------------------------------------

## 4. 最严重的识别威胁及检验

### 识别威胁

政策受益企业可能本身具有更好的发展趋势，因此创新增加并非政策导致。

例如：

高成长企业更容易获得退税，同时也更可能增加研发投入。

### 检验方法

1.  **事件研究法**

检验政策实施前处理组是否已经出现创新增长趋势。

2.  **安慰剂检验**

随机提前政策实施年份，如果仍然发现显著影响，说明结果可能由其他趋势驱动。

3.  **加入企业趋势项**

控制企业自身长期增长趋势，观察政策系数是否保持稳定。

------------------------------------------------------------------------

该样本体现博士作业要求的核心：

-   不只是运行一个DID模型；
-   必须明确因果问题；
-   说明识别假设；
-   主动面对最大识别威胁。
