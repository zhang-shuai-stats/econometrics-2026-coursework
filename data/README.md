# 课程数据

硕士第一次作业使用 WAGE1，课程原文件位置为 `作业/Data/WAGE1.DTA`。为方便运行，我把相同数据随[Stata 参考样本](../examples/masters/hw01/README.md)一并提供；详见[来源说明](../examples/masters/hw01/data/README.md)。

同学们也可自选数据并说明公开来源。

硕士第二次作业使用 [401K.DTA](401K.DTA?raw=true)，与课程 `作业/Data/401K.DTA` 内容相同。本次使用 `prate`（参与率，百分比）、`mrate`（企业匹配率，美元/美元）和 `age`（计划实施年数，年），对应第三讲第 26 页的养老金计划模型。

第二次作业的[工资参考样本](../examples/masters/hw02/README.md)使用课程 `HTV.DTA`，数据随样本提供，用于演示例 9 模型的 FWL 计算步骤。

博士第一次作业为研究设计报告，不要求提交数据，请说明计划使用的数据及获取途径。
