# 课程数据下载

本目录收录课程 `作业/Data` 下的全部 122 个文件，保留原文件名和大小写，内容与课程原文件一致。其中包括 117 个 Stata 数据文件、3 个 Excel 文件及 2 个配套文件。

**[下载全部数据 ZIP](https://github.com/zhang-shuai-stats/econometrics-2026-coursework/raw/refs/heads/main/data/course_data.zip)**。解压后得到 `Data` 文件夹，也可在下表单独下载需要的文件。

下载后请保留原文件名和扩展名；在 Stata 中读取 `.DTA` 或 `.dta` 文件时，请使用自己电脑上的实际保存路径。表中“下载”直接指向原始文件。

## 本次作业常用数据

- 硕士第一次作业：**[WAGE1.DTA](https://github.com/zhang-shuai-stats/econometrics-2026-coursework/raw/refs/heads/main/data/WAGE1.DTA)**，用于变量检查、描述统计和绘图。[作业要求](../assignments/masters/hw01.md) · [参考样本](../examples/masters/hw01/README.md)。
- 硕士第二次作业：**[401K.DTA](https://github.com/zhang-shuai-stats/econometrics-2026-coursework/raw/refs/heads/main/data/401K.DTA)**，使用 `prate`（参与率，百分比）、`mrate`（企业匹配率，美元/美元）和 `age`（计划实施年数，年），对应第三讲第 26 页。[作业要求](../assignments/masters/hw02.md)。
- 第二次作业的工资参考样本：**[HTV.DTA](https://github.com/zhang-shuai-stats/econometrics-2026-coursework/raw/refs/heads/main/data/HTV.DTA)**，使用 `wage`、`educ`、`exper`、`abil`，演示例 9 工资模型的 FWL 计算。[运行说明](../examples/masters/hw02/README.md)。

参考样本 ZIP 已包含对应数据，下载样本后可按说明直接运行。博士第一次作业以研究设计为主，不要求提交数据。
